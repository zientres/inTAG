# NFT metadata

Каталог и генератор `scripts/generate-nft-metadata.mjs` относятся к прежнему off-chain прототипу NFT.

Новая аукционная цепочка TagitalSpace не использует JSON-файлы из этого каталога: Auction Manager формирует TEP-64 metadata cell on-chain из номерного знака и передаёт её NFT Collection v1.2 при выпуске NFT.

Файлы здесь сохранены для обратной совместимости с прежними тестами и ручными экспериментами. Не запускайте генератор для новых аукционов — это не требуется.
