# TagitalSpace — смарт-контракты TON Testnet

Все адреса, конфигурации и команды в этом каталоге относятся только к **TON Testnet**. Mainnet не используется.

## Модель аукционов

Любой пользователь может подключить свой TON Testnet-кошелёк на сайте, ввести номерной знак и начать аукцион, если номер свободен в реестре TagitalSpace.

1. Сайт нормализует российский номер и проверяет его через getter `get_plate_status(uint256)`.
2. Пользователь подтверждает транзакцию создания аукциона своим кошельком.
3. Auction Manager сам назначает следующий индекс. Клиент не может выбрать или занять чужой индекс.
4. Контракт резервирует хеш номера. Повторный аукцион для уже зарезервированного или выпущенного номера отклоняется.
5. Торги продолжаются 90 минут. Текущие параметры интерфейса: начальная ставка 1 TON, минимальный шаг 0.1 TON.
6. После окончания любой пользователь может вызвать завершение аукциона. Победитель получает NFT только после подтверждения выпуска коллекцией.

Номер считается занятым внутри реестра TagitalSpace, а не проверяется по государственным базам регистрации автомобилей.

Если ставок не было, Auction Manager дожидается подтверждения пропуска индекса от коллекции и освобождает номер для нового аукциона. Если NFT успешно выпущен, номер остаётся зарегистрированным как выпущенный.

## Доступ и распределение средств

- Создание аукционов — разрешено любому кошельку.
- Ставки — разрешены любому кошельку.
- Завершение аукциона — разрешено любому кошельку после дедлайна.
- Настройка адреса фонда безопасности и вывод внутреннего баланса казны — только владельцу Auction Manager.
- Администратором NFT Collection v1.2 после настройки является Auction Manager. Пользователи не могут минтить NFT напрямую.

Распределение победившей ставки выполняется только после подтверждения выпуска NFT:
- 50% — кошелёк владельца проекта;
- 30% — внутренний баланс казны Auction Manager;
- 20% — фонд безопасности.

Если перевод пользователю не проходит, сумма сохраняется как доступный к получению кредит. При ошибке выпуска NFT ставка возвращается победителю.

## Проверка доступности номера

Для российского номера сайт и контракт используют один и тот же ключ реестра: FNV-1a 128 от UTF-8 строки `RU|НОМЕРБЕЗПРОБЕЛОВ`, передаваемый как uint256.

Getter возвращает:
- `0` — свободен;
- `1` — зарезервирован активным аукционом или ожидает обработки;
- `2` — NFT выпущен.

В реестре хранятся соответствия хеша номера и ID аукциона. При отсутствии ставок или неудачном минте запись удаляется; после успешного минта остаётся навсегда.

## NFT и метаданные

Используется NFT Collection v1.2 и NFT Item v1.2 на базе TEP-62/TEP-64.

Метаданные каждого номерного знака формируются Auction Manager непосредственно при завершении успешного аукциона и передаются коллекции как on-chain TEP-64 cell. JSON-файлы и предварительная публикация метаданных для каждого нового номера не требуются. Название, описание и изображение номерного знака входят в on-chain metadata.

Метаданные коллекции и её логотип задаются при развёртывании. Параметры роялти коллекции — 2%, получатель — кошелёк создателя.

Скрипт `scripts/generate-nft-metadata.mjs` и папки `metadata/` и `plates/` сохранены для прежнего off-chain прототипа; новая аукционная цепочка от них не зависит.

## Развёртывание в Testnet

Сборка и тесты:

```sh
acton fmt
acton build
acton check --output-format github
acton test tests/nft-v1.2
acton test tests/auction-manager
```

Первоначальная последовательность развёртывания:

1. Развернуть NFT Collection v1.2 скриптом `scripts/deployCollectionV12.tolk`.
2. Развернуть Auction Manager скриптом `scripts/deployAuctionManager.tolk`, указав адрес коллекции.
3. Настроить фонд безопасности скриптом `scripts/configureAuctionManager.tolk`.
4. Передать администрирование коллекцией Auction Manager скриптом `scripts/transferCollectionAdminToAuctionManager.tolk`.
5. Проверить адреса, статусы и getter реестра на Testnet.
6. Только после успешной проверки заполнить `auction_manager` и `collection` в `contracts/testnet.config.json`.

Перед подтверждением каждой транзакции проверьте, что кошелёк подключён к TON Testnet. Не помещайте seed-фразы и приватные ключи в репозиторий.
