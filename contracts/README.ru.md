# TagitalSpace — смарт-контракты TON Testnet

Все команды и адреса в этом каталоге относятся только к **TON Testnet**. Mainnet не используется.

## NFT-коллекция

Контракты `NftCollection.tolk` и `NftItem.tolk` основаны на официальной reference implementation Acton `nft-v1.1` и стандартах:
- TEP-62 — NFT;
- TEP-64 — метаданные;
- TEP-66 — параметры роялти.

Коллекция хранит индекс следующего NFT, метаданные коллекции, код NFT Item и параметры роялти. NFT Item поддерживает чтение данных и передачу владельца. Владелец коллекции (admin) — единственный адрес, который может выпускать NFT и менять admin.

### Изображения и метаданные

- Изображение самой коллекции — `logo.png` сайта TagitalSpace.
- У каждого NFT будет собственное изображение номерного знака с комбинацией, присвоенной этому NFT.
- JSON-файл каждого NFT будет храниться отдельно в каталоге `metadata/`; поле `image` в JSON будет указывать на изображение именно этого номерного знака.
- Базовый URL каталога метаданных: `https://zientres.github.io/inTAG/metadata/`.

При выпуске NFT контракт объединяет этот базовый URL с индивидуальным именем JSON-файла. Поэтому метаданные конкретного NFT должны быть опубликованы до его выпуска. GitHub Pages используется для тестовой версии; для неизменяемого production-хранилища позже потребуется отдельное решение, например IPFS или Arweave.

### Администратор

Для первого развёртывания в Testnet администратором временно будет указанный кошелёк создателя. После появления Auction Manager право администратора нужно будет передать его адресу через `ChangeCollectionAdmin`. До этой передачи выпуск NFT доступен только кошельку создателя.

### Роялти

Параметры, задаваемые скриптом развёртывания:
- 2%;
- получатель — кошелёк создателя.

TEP-66 публикует параметры роялти, но не может принудительно заставить сторонние маркетплейсы перечислять их.

## Тесты и сборка

Установить Acton 1.2.0.

```sh
acton build
acton test tests/nft-v1.1
```

В тестовом наборе находятся проверки коллекции, NFT Item, передачи NFT, авторизации и сквозных сценариев.

## Развёртывание в Testnet

Команда из корня репозитория:

```sh
acton script scripts/deployCollection.tolk --net testnet --tonconnect
```

Скрипт предложит подключить кошелёк и подтвердить название, описание, URL изображения коллекции и базовый URL JSON-метаданных NFT. По умолчанию уже указаны `logo.png` и каталог `metadata/` на GitHub Pages.

Транзакцию подтверждает пользователь в TON Connect. Перед подтверждением обязательно проверить, что кошелёк подключён именно к Testnet.
