# TagitalSpace — смарт-контракты TON Testnet

Все конфигурации развёртывания в этом каталоге предназначены только для **TON Testnet**.

## Текущий этап

- Базовые NFT Collection и NFT Item по TEP-62 / TEP-64 на Tolk.
- Поле `adminAddress` коллекции используется как адрес доверенного Auction Manager. В финальном развёртывании там должен находиться адрес контракта менеджера аукционов, а не обычного кошелька пользователя.
- Хранение роялти соответствует TEP-66. Планируемая роялти создателю — 2% (числитель 2, знаменатель 100).
- Публичный аукционный менеджер ещё не реализован. Не развёртывать коллекцию отдельно: до появления Auction Manager это оставит авторизацию выпуска NFT настроенной неправильно.

## Распределение

Первичная продажа на аукционе: 50% создателю, 30% казначейству, 20% фонду разработки и безопасности.
Роялти вторичной продажи: 2% создателю. TEP-66 сообщает параметры роялти, но не заставляет сторонние маркетплейсы их выплачивать.

## Сборка

Установить Acton 1.2.0 и выполнить:

```sh
acton build
```

Перед развёртыванием контракты должны пройти компиляцию и тесты. Транзакцию развёртывания владелец подтверждает в своём TON Testnet-кошельке.
